# Compta Sympa

[compta-sympa.com](https://compta-sympa.com/) · Accounting SaaS · Scriptura S.A.R.L. · *May 2023 – Feb 2026*

## What I built

- Services that process **invoices and bank documents** for accountants.
- **90% accuracy** on document classification by combining OCR (Tesseract, EasyOCR) with LLMs.
- Document extraction pipelines processing **1,200+ documents per hour**.
- Auto-fill features powered by type-checked Python ML modules (Mypy).

## Stack

Python · OCR (Tesseract, EasyOCR) · LLMs · PostgreSQL / MySQL · Docker
