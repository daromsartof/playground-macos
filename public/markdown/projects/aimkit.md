# AimKit

Chrome extension + local command · A Daroms'Art project · Free & open source

## How it works

1. Aim at any element on your web page.
2. Describe the change you want.
3. Claude Code receives the element's HTML, the CSS that applies to it (with `file:line`) and the source component.

Everything stays on your machine.

## Stack

JavaScript · Chrome Extension · Claude Code
