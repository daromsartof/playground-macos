# Palmer-immo

[palmer-immo.ch](https://www.palmer-immo.ch/) · Swiss real estate SaaS · Freelance via Daroms'Art · *Nov 2024 – Present*

## What I built

- **Scraping services** that import property listings from partner websites into the platform.
- **RAG agents** for document Q&A, built with LangChain, LangGraph and ChromaDB.
- **Self-hosted LLMs** (Ollama, Gemini) packaged in Docker and served behind a FastAPI API.

## Stack

Python · FastAPI · LangChain · LangGraph · ChromaDB · Ollama · Gemini · Docker
