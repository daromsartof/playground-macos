# About This Site

This site is inspired by macOS [Big Sur](https://www.apple.com/in/macos/big-sur/) and [Catalina](https://www.apple.com/bw/macos/catalina/), developed using [React](https://reactjs.org/), [Zustand](https://zustand-demo.pmnd.rs/) and [UnoCSS](https://uno.antfu.me/). Some of the icons are generated using [sindresorhus/file-icon-cli](https://github.com/sindresorhus/file-icon-cli).

The source code is hosted [here](https://github.com/daromsartof/playground-macos). It is a fork of [Renovamen/playground-macos](https://github.com/Renovamen/playground-macos), thanks to its author for the original work.
